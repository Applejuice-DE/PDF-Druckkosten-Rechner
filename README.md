# PDF-Druckkosten-Rechner
Eine kleine html-Seite, die die Druckkosten eines pdf-Dokument anhand von Norm-Seiten mit 5% Deckung berechnet.

Sie verfügen über den Seitenpreis Ihres Druckers (hier bietet sich der druckerchannel.de als zuverlässige Quelle an)? Dann können Sie ein beliebiges pdf-Dokument, welches gedruckt werden soll, durch dieses kleine html-Script laufen lassen. Es wird die Deckung der Seiten ermittelt und die Druckkosten werden ermittelt. Abweichende Papierformate werden umgerechnet, da die "Normseite" im Format A4 ist und über 5% Deckung verfügt. 

Zu dem Tintenpreis je Normseite kann man natürlich auch auf Wunsch den Papierpreis addieren und einstellen, so bekommt man eine recht detailierte Kalkulation der ungefähren realen Druckkosten für das entsprechende pdf-Dokument.

Die Daten werden lokal im Browser ermittelt, es erfolgt kein Upload auf externe Server.

Bitte beachten: Ich bin davon ausgegangen, dass die meisten Drucker im Farbdruck das schwarz größtenteils aus den Farbpatronen / Farbtanks mischen. Deshalb wird bei der Berechnung nicht nach SW oder Farbe unterschieden, lediglich ein anderer Preis je Normseite ist einstellbar.
Wenn der Drucker also schwarze Tinte im Farbdruck einsetzt - und die Tintenpreise zwischen Schwarz und Farben unterschiedlich sind, kommt es deshalb zu leichten Abweichungen.

# PDF Printing Cost Calculator
A small HTML page that calculates the printing costs of a PDF document based on standard pages with 5% coverage.

Do you know the cost per page for your printer (druckerchannel.de is a reliable source for this)? If so, you can run any PDF document you want to print through this small HTML script. The page coverage is determined, and the printing costs are calculated. Non-standard paper sizes are converted, since the “standard page” is A4 format and has 5% coverage.

In addition to the ink cost per standard page, you can of course add the paper cost if desired, giving you a fairly detailed estimate of the approximate actual printing costs for the PDF document in question.

The data is calculated locally in the browser; nothing is uploaded to external servers.

Please note: I’ve assumed that most printers mix black ink primarily from the color cartridges or tanks when printing in color. Therefore, the calculation does not distinguish between black-and-white and color; only a different price per standard page can be set.
So if the printer uses black ink in color printing—and the ink prices for black and color differ—this will result in slight variations.
